## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Path Browser** | Full VPE ability tree for every psycaster path with upgrade costs |
| **Build Planner** | Plan your pawn's ability investments across multiple VPE paths |
| **Psyfocus Calc** | Estimate psyfocus cost for planned ability sets |
| **Role Optimizer** | Compare builds optimized for combat, support or utility roles |
